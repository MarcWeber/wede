Hello, welcome to mobile development.

The hamburger menu allows to add tabs.
Clicking the tabs shows/hides all tabs of the same time.
On desktop you can make the tabs float above or dock.
Collaborative editing is possible.

Long tapping on the tabs, files, search results allows
to lock, open or close multiple items at the same time.

ctrl/cmd+s save 
ctrl/cmd+p quick open
ctrl/cmd+shift+p command palette

open   | selected
close  | selected
lock   | selected
unlock | selected
close also locked (close all tabs)

lock/unlock: locked tabs can't be closed
close -> current tab
selected -> close all selected tabs
types explained:

T1 files
shows a directory tree so that you can open files
#long_press_selectable: open/rename/remove

T2 search
search in files contents and file names

T3 code
toggles visibility of code file tabs

T4 web_view [new]
toggles visibility of web views. Most external websites disallow embedding
So its likely that you need to use different tab
(thus might go away)

T5 git
Allows to stage and commit files

T6 api
Allows to test apis (might go away, is there any use to this?)

T7 settings
The settings

T8 log_view -> #closes_menu
allows to watch log files

T9 help

#long_press_selectable: tab long to change to select mode, hold long again or
right click to see menu
